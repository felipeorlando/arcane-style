# Arcane style

Two Cursor skills for an original-character look: painted faces with solid volume, ink contours, hard shadow shapes, and a short list of colors. One skill is the still character bible. The other is how a scene in that look is staged and cut.

These skills describe a visual grammar. They do not name a creator, and the prompt blocks do not ask for any existing character, actor, or film.

## When to use which

| Skill | Use it when |
| --- | --- |
| [`skills/character-sheet/SKILL.md`](skills/character-sheet/SKILL.md) | You need a still character bible or a poster plate: brush name, action hero, turnaround, detail callouts, color chips, tagline. |
| [`skills/cinematic-scene/SKILL.md`](skills/cinematic-scene/SKILL.md) | You need a moving scene in the same render: one place, motivated light, hard cuts, weighty motion, readable silhouettes. |

Use the character skill first when a scene should stay on-model. Use the scene skill alone when the shot is the deliverable.

Point an agent at `skills/`, or copy a skill folder into `.cursor/skills/`.

## What turned out to be stable

The three-column bible is a real, repeated product: action hero on the left, neutral front/side/back turnaround in the center, detail callouts and color chips on the right, brush name and a short tagline. It is the layout to reuse for a new character.

It is not the only layout in the recent work. From 28–30 Sep 2026 the public posts switch to poster plates (one figure, a split pair, or a lineup) with the same ink, splash, and type, and no turnaround. The clips from that stretch play the scene in the top half of a square frame and hold one of those posters in the bottom half.

The render is what travels from the bible, to the poster, to the scene: half painted illustration, half solid form. A smoother sunlit 3D piece and a photoreal widescreen clip from 29 Sep are a different family. They are noted in the scene skill so they are not mixed in.

## What was actually looked at

Public posts on X were read through the API, including full long-post text. Stills were downloaded. Eleven clips were checked by pulling frames a few seconds apart (the files are 24 fps; the square ones are about 14–20 seconds). Audio was not played. A web-search tool hit a rate limit, so dating relied on the posts and on the stills supplied with the task.

The six supplied street-athlete bibles match the three-column grammar. Searches for their printed names and taglines did not return those sheets. The same layout is on the public timeline on 6, 7, and 22 Sep 2026. Sources and dates are listed at the bottom of each skill.
